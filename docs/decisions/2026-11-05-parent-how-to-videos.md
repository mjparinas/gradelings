# Parent how-to videos

**Parent how-to videos** (November 5, 2026, files in `public/videos/parents/`): short screen-recorded videos of the real parent area (demo child only), narrated with Supertonic, self-hosted with captions and the logo bottom-right, made by `scripts/help-videos/screens.py` (`docs/video-help/README.md`). They name no price or payment so they can show in the store apps. Melvin wants each video offered on first use of its feature plus a library page to rewatch; the teacher-videos work builds that shared library and player.
