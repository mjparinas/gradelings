# A new teacher's first class is set up in one form (Melvin, November 17, 2026)

Nine teacher accounts had signed up but almost none had any student practice. A teacher with no classes now sees one short form ("Set up your class") with the class name, grade, province or state and an optional box to paste students' first names. Creating the class adds those students, then opens the Students tab with a "Your class is ready" panel: print login cards, print take-home slips or copy the note for Google Classroom or email, and open Homework to pick a first unit. Teachers who already have a class see the usual form, unchanged.

Why: the empty class list and a separate trip to add students were where new teachers stopped. Code: `ClassList` and `Ready` in `src/components/teachers/TeacherApp.tsx`.
