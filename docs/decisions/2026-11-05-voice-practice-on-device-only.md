# Voice practice, on-device only

**Voice practice, on-device only** (November 5, 2026; flag `voice-practice`, off by default, so the owner turns it on per family under Admin > Users > Flags): a child can answer picture-naming and counting questions out loud (`say` kind, Pre-K to Grade 1: first sounds, count to 5 and 10, numbers to 20). It is free. A parent switches it on per child in Settings > Advanced options ("Let them answer out loud", `ChildSettings.voice`) and downloads the listening model once (about 65 MB, Whisper tiny.en run by transformers.js in a web worker, `public/whisper-worker.js`, `src/lib/whisper.ts`; Cache Storage `gradelings-whisper`, files in `public/whisper/1/` fetched by `scripts/fetch-whisper.mjs`, hashes in `src/lib/whisper-manifest.json`, never committed). Audio is never uploaded, stored or logged, and the microphone is open only while a child is answering. A class student account never listens (schools were promised no microphone), whatever its settings say. Matching is forced-choice (`src/lib/speechMatch.ts`): hearing the right word gives credit, anything else is "not heard" and never a wrong answer, and after two tries taps appear. Without the flag, the switch, the model or a working microphone, a `say` question is simply the tap question, so no unit depends on voice. Pages send `Permissions-Policy: microphone=(self)`. Keep `/privacy/` true to this. The model is self-hosted from the GitHub release `whisper-tiny-en-1` (never replace a release's assets; make `-2`), with the pinned Hugging Face and npm copies as a hash-checked fallback. Accuracy on real children's voices is untested: judge it with children before widening the flag.
