# Fewer merge conflicts and faster CI

**Fewer merge conflicts and faster CI** (November 5, 2026): conflicts between pull requests came from two places: every pull request appended to the Decisions list at the end of `AGENTS.md` (34 edits in three days), and `src/content/locks/sizes/*.json` were rewritten for every framework by any change to a shared grade file. Decisions now live one file each in `docs/decisions/`, and `npm run curriculum:lock` keeps a recorded size while the real one is within the 10% slack. Pure `src/lib` tests share workers, and content-only pull requests skip the browser e2e jobs. Left for the owner: generating the locks in CI instead of committing them would remove the remaining lock conflicts (`locks/*.json` and `locks/dates/*.json`, which conflict only when two pull requests change neighbouring units), but loses the visible diff of which frameworks a change reaches.
