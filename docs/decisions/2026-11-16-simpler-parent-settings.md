# Simpler parent settings (November 16, 2026)

Melvin: the parent settings are too complicated; the fewer decisions a parent has to make, the better. ("Keep going", November 16, 2026, after the proposal in the thread.)

- Per-child Settings now shows five things: Subjects, Read aloud, Easier reading, Calm mode and Arcade games (plus Sounds). Fine controls sit under "More reading options" and "Customize calm mode".
- Removed from the page (age defaults apply): daily goal slider, learn-to-play ratio sliders, daily game cap, the lighter/stretch goal switch, "Hints count as first try", the free-play choice, and the timers choice moved under Customize calm mode.
- Nothing is deleted or migrated: the same synced fields are read, so a parent's earlier custom values keep working and only new choices are not offered.
- Account: the read-aloud voice section is collapsed ("change or fix"); Progress emails offer Weekly summary or None.
- Overview: the weekly goal, focus unit, goal plan and reward tools are folded under "Ways to help (optional)".
- Voice practice (Whisper) auto-enable is handled separately (`2026-11-09-voice-practice-on-by-default.md`).
