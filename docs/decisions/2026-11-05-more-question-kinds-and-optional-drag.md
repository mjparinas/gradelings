# More question kinds and optional drag

**More question kinds and optional drag** (November 5, 2026): beyond choice, input, order, sort, build, coins, shade and place, questions can be `match` (tap a pair), `multi` (select all), `highlight` (tap words in a sentence), `mistake` (tap the wrong step), `fill` (word bank) and `tiles` (build a word, sentence or equation), each with a component in `src/components/questions/` and a case in `src/content/fairness/question.ts`. Units get them through `src/content/rich/` (`RICH` per grade in `rich/units.ts`, applied by each grade's `index.ts`); add a unit there to give it variety, then run `npm run curriculum:lock`. Pre-K allows `match` (pictures, at most 3 pairs) and no other new kind. Dragging (`src/lib/drag.ts`, `useDrag`) is an extra way to answer order, sort, match, fill and tiles; tapping is always the default and works with keys and read-aloud. The new kinds are not in Speed Run, live questions, the placement test or the practice sheet. Voice input waits on the owner's privacy decision (`on-device only`; see the project's `question-types` notes).
